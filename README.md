# Asociación de Fútbol Local Nueva Calera de Tango

Sitio web para consultar programación, resultados, tablas de posiciones y goleadores de las temporadas 2026 y 2027.

## Reglas de puntuación
- Primera Adulta: triunfo 4 puntos, empate 2 puntos, derrota 0 puntos.
- Demás categorías: triunfo 3 puntos, empate 1 punto, derrota 0 puntos.
- Primer criterio de desempate: diferencia de goles.

## Estado del proyecto
Primera estructura visual del sitio. Aún falta integrar una base de datos, autenticación segura de administrador y la carga real del fixture PDF. No ingresar información oficial ni contraseñas en esta versión inicial.

## Publicación
Se puede publicar mediante GitHub Pages una vez configurada la fuente de publicación en Settings > Pages. La publicación estática no proporciona por sí sola autenticación ni almacenamiento compartido de resultados.
